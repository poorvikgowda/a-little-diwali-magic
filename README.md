# 🪔 A Little Diwali Magic ✨
### *A Magical Diwali Surprise Website for My Special Friend*

A breathtaking, cinematic, and interactive Diwali greeting website crafted with festive lights, glowing diyas, realistic fireworks, thoughtful mature friendship wishes, and heartfelt memories.

---

## 🌟 Highlights & Features

- **✨ Deep Midnight Dream Atmosphere:** Royal purple, midnight navy, glowing golden amber, and soft festive lighting.
- **🪔 Sacred Diyas & Rangoli (7 Auspicious Diyas):**
  - Hope, Peace, Joy, Health, Prosperity, Laughter, Wisdom.
  - Symmetrically arranged around an intricate animated sacred geometry Rangoli.
  - Interactive "Light Up Another Diya" button and click-to-intensify flame effects.
- **🎆 Spectacular HTML5 Canvas Fireworks:**
  - 6 distinct firework styles: Golden Brocade, Peony Pink, Royal Violet, Blossom, and Sparkling Anar (Fountain).
  - Tap or click anywhere in the night sky to launch custom fireworks.
  - "Make a Wish ✨" button that bursts fireworks and reveals heartfelt blessings.
- **🔊 Realistic Procedural Diwali Sound & Indian Music:**
  - Powered by Web Audio API — 100% self-contained, zero external audio loading errors, zero latency, works offline!
  - Realistic distant booms, aerial rocket whistles, thuds, crackles, sparkle chimes, and diya ignition whooshes.
  - Peaceful Indian instrumental ambient background music (Tanpura drone + Bansuri/Sitar Raag harmonics).
  - Independent Music and SFX toggles with individual volume controls.
- **❤️ Beautiful Friendship Wishes (Six Thoughtful Wishes):**
  - Six mature, thoughtful, and genuine friendship wishes presented in a floating golden dream card carousel or constellation grid.
  - Beautiful closing wish: *"Always wishing the very best for you. ❤️🪔"*.
- **💌 Secret Message — A Special Letter:**
  - Luxurious golden envelope with a glowing heart-shaped wax seal.
  - Unfolding flap animation with emerging golden light rays and vintage parchment typography.
- **🎆 The Final Surprise — "One Last Thing...":**
  - Cinematic 4-step sequence: background darkening, central glowing light, and slow line-by-line reveal with exact emotional breathing space.
  - Grand celebration finale: continuous fireworks barrage, golden fanfare, confetti shower, and glowing hearts.
- **📱 Fully Responsive:** Beautiful across iPhones, Android devices, tablets, laptops, and desktops.

---

## 🚀 How to Run Locally

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Start the development server:**
   ```bash
   npm run dev
   ```

3. **Open in browser:**
   Navigate to `http://localhost:3000` (or the port displayed in terminal).

4. **Production Build:**
   ```bash
   npm run build
   npm run preview
   ```
